# PLAN — implementing "System X" from design.json

The design has no goal, description, representation descriptions, references or images.
Everything below the expression level is my interpretation; defaults were taken without
waiting for confirmation (as instructed).

## Interpretation (one application, three modes)

All three processes revolve around spatial input on a canvas that is turned into images.
Only `model_1 generate/modify` produce `visual` artifacts, `model_2` produces `language`.
With only the Claude CLI available, **visual artifacts are SVG images** generated by Claude.

| Actor | Role in the app |
| --- | --- |
| `tool_1` | **stroke beautifier**: smooths/simplifies freehand strokes and recognises clean shapes (line, rectangle, ellipse, triangle, polygon, freeform) |
| `tool_2` | **scene engine**: extrudes a 2D ground-plan layout into a 3D block scene, and applies camera changes to it |
| `tool_3` | **composer / renderer**: composes items into layouts and records, translates between representations (render to SVG, derive camera, derive selections + instructions, speech → category), composites images |
| `model_1` | **image model** (Claude emitting SVG): generates and region-edits images |
| `model_2` | **text model** (Claude emitting JSON): writes a description per record |

- **Mode 1 — "Scene"** (process 1): draw building footprints on a ground plan → beautify → layout → 3D block scene → camera → orbit the camera → render → image from render → paint edit regions with an intent brush → region selections + edit instructions → edited image (before/after kept).
- **Mode 2 — "Sketch"** (process 2): sketch on a blank canvas → beautify → render sketch + auto-generated textual description of the sketch → image.
- **Mode 3 — "Voice collage"** (process 3): type a global prompt → draw boxes → move/resize boxes → record a voice note per box → speech → category label per box → records → description per record (model_2) → image per record (model_1) → composite collage.

## Open choices and defaults taken
- Stack: Vite + React + TypeScript frontend, Express (TS via tsx) backend, no DB (state in memory in the browser).
- Model provider: one function `callModel()` in `server/provider.ts` spawning `claude -p --output-format json` with `CLAUDECODE` removed, tools disabled.
- Visual medium: SVG (validated, sanitised, displayed via `<img>` data URIs so scripts cannot run).
- Audio → text: browser Web Speech API live transcript during recording (with a typed-transcript fallback when unsupported); the category mapping itself is deterministic keyword matching.
- Persistence: none; export buttons for SVGs.
- Layout: tabbed modes, left = canvas/stage, right = pipeline panel listing steps with their state.
